# Scheda Guerriero

App web per la scheda di allenamento (2 giorni): serie, pesi, recuperi, varianti, storico, grafici e crescita muscolare.

- Si apre da Safari e si aggiunge alla schermata Home.
- Accesso con Google o email; dati su Firebase (Firestore), anche offline.
- Condivisione in sola lettura con altri account (pagina **Amici**).

`firestore.rules` contiene le regole di sicurezza da incollare in Firebase → Firestore → Regole.
